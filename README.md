# Project Website with Database
A simple shoe store website using PHP, MySQL, HTML, and CSS.

## Features
- Display store name and welcome message
- Show product list from database
- Display product names and prices
- Clean and responsive design

## Database Setup
1. Create a MySQL database named `shoe_store`
2. Import `database-setup.sql`
3. Check the MySQL username/password in `db.php`
4. Put the project in a PHP server such as XAMPP
5. Open `index.php` in the browser

## Files
- `index.php` — Main website page
- `db.php` — Database connection configuration
- `style.css` — Website styling and design
- `database-setup.sql` — Database and table setup
